DataGraph.city provides AI‑assisted querying of urban data across multiple cities via the Model Context Protocol (MCP). Users can obtain free API keys for personal use and paid plans for commercial applications. The platform offers GraphRAG‑powered city intelligence, enabling natural‑language queries about properties, transit, civic programs, and more, without writing code. It is currently in private beta, offering documentation, quick‑start guides, and pricing information on its website.

**Areas:** UrbanData · AI · MCP · GraphRAG · PrivateBeta

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages.
